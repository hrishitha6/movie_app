# 🎬 CineScope

A movie search web application built using Python, Streamlit, and the OMDb API.

## Features

- 🔍 Search any movie instantly
- 🎭 View movie genre
- ⭐ IMDb ratings
- 📅 Release date
- ⏱ Runtime
- 🎬 Cast information
- 📖 Movie plot summary
- 🖼 Movie poster display
- 🎨 Custom Streamlit UI styling

## Technologies Used

- Python
- Streamlit
- Requests
- OMDb API

## Installation

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Navigate to the project folder:

```bash
cd movie_app
```

Install dependencies:

```bash
pip install streamlit requests
```

Run the application:

```bash
streamlit run movie_web.py
```

## Project Structure
